# Web Prototype

这是生活打卡工具的 Web 版本。它不依赖 iOS、Xcode 或模拟器，可以直接在 Windows 浏览器中运行。

## 运行

在项目根目录执行：

```powershell
python -m http.server 4173 --bind 127.0.0.1 -d web-prototype
```

访问：

```text
http://127.0.0.1:4173/
```

## 手动验证

1. 打开“今日打卡”。
2. 输入“打卡点”，例如餐厅、学校、公园。
3. 手动输入“具体地址”，或点击“使用当前位置”并授权浏览器定位。
4. 调整“环境”“服务”“味道”“性价比”等评分。
5. 添加一个自定义评分标签，再删除一个不需要的评分标签。
6. 上传 1 到 3 张本地图片。
7. 填写备注。
8. 点击“生成图片”，确认出现打卡长图预览和下载按钮。
9. 点击“保存打卡”。
10. 查看“历史记录”列表。
11. 点击历史记录，确认右侧详情显示时间、打卡点、具体地址、记录方式、评分、图片和备注。
12. 刷新页面，确认记录仍然存在。

## 数据说明

记录保存在当前浏览器的 `localStorage` 中。清空浏览器站点数据后，Web 原型记录会被删除。

图片以 Data URL 存入本地记录，适合原型验证；如果后续要做正式产品，建议改为后端对象存储或浏览器 IndexedDB。
